# TensorFleet Simple Robot Project Template

This directory hosts the simple robot starter project for ground robots focused on velocity control, LiDAR avoidance, and YOLO vision.

## Quickstart

- `simple-robot_quickstart.md` – walkthrough with setup steps, dependencies, and example scripts.

## Template contents

- `requirements.txt` – Python dependencies for the simple robot demos.
- `config/robot_config.yaml` – robot and network defaults.
- `launch/` – optional ROS 2 launch files.
- `src/` – sample Python nodes (`robot_mover`, `obstacle_avoider`, `vision_yolo`).
- `.env.example` – environment variable template for ROS bridge and proxy settings.

Follow the quickstart for step-by-step instructions.

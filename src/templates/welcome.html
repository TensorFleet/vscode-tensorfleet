TensorFleet integrates drone simulations, ROS/ROS 2, and AI workflows directly into VS Code.

  • Connect to robotics simulation using ROS protocols and program robots
  • Visualize simulation and sensor data in real time
  • Access the drone with a map view and mission control features

First, sign in to your TensorFleet account so we can connect to your VM manager and services.

Logged in

The login/signup window will open in your browser. Once completed, we’ll mark this step as done.

Let’s create a new TensorFleet project from templates.

  • Choose a folder and a project name
  • We’ll scaffold config, missions, and source layout
  • You can open the project in this window or a new one
Project created! You can proceed to panel selection.

Pick which panels you want to open initially. You can always open the others later.

Gazebo Simulation
World view, sensors, overlays.
Teleops
Keyboard-based drone control.
Map / Mission Control
Global view and missions.
3D Sensor View
3D data from drone sensors.
Raw Messages
ROS 2 traffic for debugging.
Image View
Camera feeds and overlays.

You can always open or close panels later from the TensorFleet view.
